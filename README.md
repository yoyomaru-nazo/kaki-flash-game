# 柿か杮か？ 一瞬見分けクイズ

一瞬だけ表示される漢字が「柿（かき）」か「杮（こけら）」かを当てるWebゲームです。

## 遊び方

- 表示時間をスライダーで設定（50〜2000ミリ秒）
- 「ゲームスタート」を押すと、漢字が設定した時間だけ一瞬表示されます
- 「柿」か「杮」のボタンを押して回答。全10問
- 得点は表示時間が短いほど高くなります：正解で「(2100 − 表示ミリ秒) ÷ 20」点（切り上げ）

## 見分け方

- 柿：右側の上部が「点＋横棒」で離れている
- 杮：横棒が一本で貫かれている

## 技術

- HTML / CSS / JavaScript の単一ファイル（`index.html`）のみ。ビルド不要
- GitHub Pages で公開
