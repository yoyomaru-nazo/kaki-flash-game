# 柿か杮か？ 扉の隙間クイズ

扉の隙間の中を右から左へ通り抜ける漢字が「柿（かき）」か「杮（こけら）」かを当てるWebゲームです。

## 遊び方

- 「ゲームスタート」を押すと3・2・1のカウントダウンのあと開始
- 扉の隙間から見える一瞬の形で判断し、「柿」か「杮」のボタンを押して回答。全10問。不正解は0点
- 設定は画面の上のほうにあり、決めたらすぐ下のスタートボタンを押すだけです

## 難易度と得点

- 隙間の幅（30〜150px）と速さ（横切り時間 400〜3000ミリ秒）をそれぞれ設定可能
- 難易度は「隙間の狭さ × 速さ」の掛け算で点数化：正解で 100 ×（160 − 隙間px）÷ 130 ×（3400 − 横切りms）÷ 3000 点（四捨五入、最低1点）。最も難しい設定（隙間30px・400ms）で100点
- 連続正解ボーナス：基本点 × 10% ×（連続数 − 1）（四捨五入）が加算されます。10連続目は基本点の+90%、全問正解なら総合計は基本点合計の1.45倍。結果画面には最大連続正解も表示され、X投稿文にも入ります
- フォント・文字サイズ（40〜240px）・表示位置・傾き・太さ・縦横比は問題ごとに大きくランダムで変わります（同じ場所を凝視するだけでは見分けにくい仕様）
- 結果画面から、点数・設定・ゲームへのリンク・ハッシュタグ #柿か杮か を入れてXに投稿できます

## 見分け方

- 柿：右側の上部が「点＋横棒」で離れている
- 杮：横棒が一本で貫かれている

## 技術

- HTML / CSS / JavaScript の単一ファイル（`index.html`）のみ。ビルド不要
- GitHub Pages で公開
