# 柿か杮か？ 一瞬見分けクイズ

一瞬だけ見える漢字が「柿（かき）」か「杮（こけら）」かを当てるWebゲームです。2つのモードがあります。

## モード

### 一瞬表示モード

- 表示時間をスライダーで設定（50〜2000ミリ秒）
- 漢字が設定した時間だけ一瞬表示されます
- 得点は表示時間が短いほど高くなります：正解で「(2100 − 表示ミリ秒) ÷ 20」点（切り上げ）

### 扉の隙間モード

- 扉の隙間の中を、文字が右から左へ通り抜けます。隙間から見える一瞬の形で判断します
- 隙間の幅（30〜150px）と速さ（横切り時間 400〜3000ミリ秒）をそれぞれ設定可能
- 難易度は「隙間の狭さ × 速さ」の掛け算で点数化：正解で 100 ×（160 − 隙間px）÷ 130 ×（3400 − 横切りms）÷ 3000 点（四捨五入、最低1点）。最も難しい設定（隙間30px・400ms）で100点

## 共通ルール

- 「ゲームスタート」を押すと3・2・1のカウントダウンのあと開始
- 「柿」か「杮」のボタンを押して回答。全10問。不正解は0点
- フォント・文字サイズ（40〜240px）・表示位置・傾き・太さ・縦横比は問題ごとに大きくランダムで変わります（同じ場所を凝視するだけでは見分けにくい仕様）

## 見分け方

- 柿：右側の上部が「点＋横棒」で離れている
- 杮：横棒が一本で貫かれている

## 技術

- HTML / CSS / JavaScript の単一ファイル（`index.html`）のみ。ビルド不要
- GitHub Pages で公開
